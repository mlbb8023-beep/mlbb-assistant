# MLBB Assistant — Full API edition

## Что умеет
- Получает полный актуальный каталог героев из публичного JSON API.
- Открывает подробную карточку героя и выводит поля, которые опубликованы источником (включая навыки и характеристики, если они доступны).
- Загружает предметы, боевые заклинания, эмблемы, тир-лист и патчи.
- Поиск и фильтрация героев по ролям.
- Адаптивный интерфейс и Telegram Mini App SDK.
- Работает как статический сайт на GitHub Pages. Для этих справочных функций отдельный сервер не нужен.

## Важно про полноту и актуальность
Данные загружаются из открытого community API MLBBDex: https://mlbbdex.com/api-doc. Это не официальный API Moonton. Источник описывает каталог героев, подробные страницы героев, предметы, эмблемы, заклинания, облики, патчи и рейтинги. Обновление каталога у источника выполняется периодически, поэтому это не гарантия моментальной синхронизации с игровым клиентом.
В карточке показываются только поля, реально возвращаемые API. Неизвестные навыки, характеристики и сборки не выдумываются. Если API недоступен, приложение использует локальный резервный список из 10 примеров.
Данные каталога основаны на Mobile Legends Wiki и распространяются по CC BY-SA. При распространении изменённого набора данных соблюдай условия лицензии и сохраняй указание источника. Код проекта — отдельный пользовательский код.

## Публикация
1. Создай публичный репозиторий `mlbb-assistant` на GitHub.
2. Распакуй архив и загрузи СОДЕРЖИМОЕ папки проекта в корень репозитория.
3. Commit changes.
4. Открой Settings → Pages.
5. Source: Deploy from a branch; Branch: `main`; Folder: `/ (root)`; Save.
6. Через 1–3 минуты открой `https://ТВОЙ-ЛОГИН.github.io/mlbb-assistant/`.

## Telegram Mini App
1. Открой @BotFather → /mybots → выбери бота.
2. Настрой Mini App / Main App или используй /newapp.
3. Укажи HTTPS-адрес GitHub Pages.
4. При необходимости настрой Menu Button на тот же URL.
5. Запусти бота и открой Mini App.

Не добавляй токен бота в этот проект: статический сайт не должен хранить секреты.

## Если отображается «Нет связи с базой»
- Открой сайт напрямую в Safari/Chrome и проверь интернет.
- Убедись, что адрес `https://mlbbdex.com/api/v1/heroes` открывается.
- Если API недоступен в сети, приложение не сможет загрузить полный каталог; резервный набор содержит только 10 героев.
- Это ограничение внешнего API, а не GitHub Pages.

## Аватары и контрпики (обновление)
- В карточках героев используются портреты/иконки, если API возвращает соответствующие изображения.
- В профиле героя дополнительно запрашивается `/api/v1/heroes/{slug}/counters`.
- Контрпики выводятся группами на основании статистики, которую отдаёт API.
- Интерфейсные подписи, названия разделов, роли, линии и подписи контрпиков отображаются по-русски. Если источник не предоставляет русское описание навыка/предмета, приложение не показывает английский абзац и честно сообщает, что русский перевод пока недоступен.
- Публичная документация MLBBDex перечисляет доступные языки API: английский, французский, итальянский, испанский и индонезийский; русского языка среди локалей API нет. Поэтому для полного качественного русского перевода описаний потребуется отдельный проверенный переводной слой.
